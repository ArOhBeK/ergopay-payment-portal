REST API

Prefer to integrate programmatically? You can call the underlying endpoints directly:

  • GET /payment/auth – generate an ErgoPay address request.
  • POST /payment/addrequest – create a payment request.
  • GET /payment/state/<requestId> – poll the payment status.
  • GET /payment/getrequest/<requestId> – retrieve the payment ErgoPay payload.
  • POST /api/nft-mint – prepare an NFT mint request.
  • GET /tx/<txId> – fetch the mint transaction ErgoPay payload.
  • POST /callback/<txId> – optional callback for signed transactions.

Built for quick deployments. Use this UI or call the REST API directly.
