REST API

Prefer to integrate programmatically? The original REST API remains unchanged:

  • POST /payment/addrequest – create a request.
  • GET /payment/state/<requestId> – poll the status.
  • GET /payment/getrequest/<requestId> – retrieve the ErgoPay payload.

Built for quick deployments. Use this UI or call the REST API directly.
